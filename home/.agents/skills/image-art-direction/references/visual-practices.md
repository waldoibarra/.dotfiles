# Visual practices for still images

## Separate reference roles

For portraits, choose current, complementary photographs with visible features and
compatible appearances.
Use a separate full-body reference for proportions; close-ups cannot establish leg length or
garment drape.
Assign each style reference a visible property, such as expression, palette, or edge softness.
Exclude incidental props and people. Keep generated proofs as composition references, not
identity evidence.
Compare eyes, nose, asymmetry, expression, and complexion against real photographs.
The subject decides likeness; a polished face alone proves nothing.

## Describe relationships a viewer can check

Translate “distant” into scale, softer edges, lower contrast, and foreground occlusion.
Name which edges the foreground hides. Judge the focal point before counting decorative details.
Specify where colored light lands and which surfaces should retain their natural color.
For reflections, relate color placement to the source and break highlights along the surface
texture.
A brighter patch can be noticeable without reading as a reflection.

## Match precision to the technique

Whole-scene edits can satisfy one detail while changing accepted color, pose, or identity.
For one local change, protect surrounding regions with a mask or composite.
Compare protected pixels against a baseline at identical resolution.
An unchanged face verifies preservation, not whether the edit looks convincing.

For exact lettering, check spelling, script, visibility, and placement on the actual garment.
If generation repeatedly fails, try separate lettering warped over folds with inherited
shadows and texture.
Treat that method as a candidate until the garment crop and intended display both pass.
